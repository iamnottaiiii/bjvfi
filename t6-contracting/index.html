How a project runs

Simple, predictable, no mystery. This is the process on every job, big or small.

  • 1. Call. Describe the project. Send photos if you have them.
  • 2. Site visit. We walk it, measure it, talk options and budget.
  • 3. Written estimate. Scope, price, and timeline in writing.
  • 4. Build. One coordinated crew through the final walkthrough.
